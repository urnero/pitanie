# ПИТАНИЕ

Дневник питания для телефона: нормы белков, жиров, сложных и простых углеводов в г/кг массы тела, учёт еды, воды и веса, справка. Профили: Гриша и Таня.

- Одна страница (PWA), без сервера и регистрации. Работает офлайн после первого открытия.
- Данные хранятся только в браузере телефона (`localStorage`). Копия: «Профиль → Сохранить копию».

## Файлы
- `index.html` — приложение целиком (разметка, стили, логика).
- `foods.js` — база продуктов, значения на 100 г. id не менять.
- `sw.js` — офлайн-кэш. При изменении списка файлов поднять `CACHE`.
- `manifest.webmanifest`, `icons/` — установка на главный экран.
- `план.html` — исходный план приложения.

## Обновление
Изменить файлы → `git commit` → `git push`. GitHub Pages обновится за 1–2 минуты, телефон подхватит новую версию при следующем открытии (иногда со второго раза).
