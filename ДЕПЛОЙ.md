## Шаги деплоя
1. **Репозиторий.** Создать на GitHub пользователя публичный репозиторий `pitanie` (пустой: без README,
   .gitignore и лицензии). Способы:
   - коннектор/MCP GitHub, если он есть в сессии (create repository);
   - встроенный браузер: `https://github.com/new` (пользователь должен быть залогинен), Repository name
     `pitanie`, Public, Create repository;
   - `gh repo create pitanie --public --source "C:\Г\ПИТАНИЕ" --push` (если `gh` установлен и `gh auth login` пройден).
   GitHub Pages на бесплатном аккаунте работает только с **публичным** репо. Данные пользователей
   в репо не попадают: они хранятся только в браузере телефона.
2. **Push.**
   ```bash
   cd "/c/Г/ПИТАНИЕ"
   git remote add origin https://github.com/<логин>/pitanie.git
   git push -u origin main
   ```
   Git Credential Manager откроет окно входа: пользователь жмёт «Sign in with your browser» → Authorize.
3. **Включить Pages.** Settings → Pages → Build and deployment → Source: *Deploy from a branch* →
   Branch `main`, папка `/ (root)` → Save. Или через API:
   `gh api -X POST repos/<логин>/pitanie/pages -f "source[branch]=main" -f "source[path]=/"`.
4. **Проверка.** Через 1–2 минуты открыть `https://<логин>.github.io/pitanie/`: страница грузится,
   в консоли нет ошибок, `manifest.webmanifest` и `sw.js` отдаются 200, service worker
   зарегистрирован (DevTools → Application). Дать ссылку пользователю.

## Установка на телефон (сказать пользователю)
- Android, Chrome: открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone, Safari: «Поделиться» → «На экран „Домой“».
- Гриша и Таня: у каждого свой телефон и свой профиль (переключатель в шапке). Данные между
  телефонами **не синхронизируются**. Перенос и бэкап: Профиль → «Сохранить копию» / «Восстановить из файла».

## Обновления после деплоя
Правка → `git commit` → `git push`. Pages обновится за 1–2 минуты. Телефон берёт новую версию
при следующем открытии (sw: stale-while-revalidate). Если меняется список файлов приложения,
поднять `CACHE` в `sw.js` (`pitanie-v1` → `pitanie-v2`) и дописать файл в `SHELL`.
